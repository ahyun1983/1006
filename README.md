# 천안시 보육정책 — 인터랙티브 웹 프레젠테이션

원본 PDF 10장을 각각 고품질 WebP 이미지로 포함한 정적 웹사이트입니다. 원본 문구·이미지·인포그래픽은 슬라이드 화면에서 유지되며, 별도 내용 패널에서 핵심 내용을 텍스트로도 볼 수 있습니다.

## 실행 방법

`index.html`을 더블클릭해 브라우저에서 열거나 GitHub Pages로 게시하세요. 서버·데이터베이스·외부 라이브러리·인터넷 연결이 필요하지 않습니다.

## GitHub Pages 게시

1. GitHub에서 새 저장소를 생성합니다.
2. 이 폴더의 `index.html`과 `assets/` 디렉터리를 저장소 최상위에 업로드합니다.
3. 저장소 **Settings → Pages**에서 **Deploy from a branch**, **main**, **/(root)**를 선택하고 저장합니다.
4. GitHub Pages에 표시되는 주소로 접속합니다.

`index.html`과 `assets/`가 같은 수준에 있어야 합니다. `assets/slide-01.webp`부터 `slide-10.webp`까지 모두 업로드해야 합니다. 하위 경로에서도 작동하도록 상대경로를 사용합니다.

## 조작법

- 화면 양쪽 이전·다음 버튼 / 모바일 좌우 스와이프
- 방향키, Page Up/Down, Home/End, 스페이스바
- 슬라이드 위에서 마우스 휠
- G: 전체보기, I: 내용보기, F: 전체화면, Esc: 패널 닫기
- `#slide-4`와 같이 주소 끝에 해시를 붙여 특정 슬라이드에 직접 접근

## 주의사항

슬라이드는 원본을 이미지로 보존하여 PDF의 디자인을 완벽하게 유지하는 방식입니다. 원본 속 글자·차트는 이미지에 포함되므로 개별 요소를 웹상에서 편집할 수 없습니다. 별도 내용보기 패널은 텍스트 접근성을 보완합니다. 지원금 및 정책 세부사항은 원본 PDF 내용이며 최신 행정 안내와 차이가 있을 수 있습니다.
